💻 Windows PC 사용자

GoodbyeDPI 추천. 인터넷 속도 저하(0%)가 없으며, 1회 실행 후 백그라운드 자동 동작.

📱 모바일 (안드로이드/iOS)

유니콘 HTTPS 추천. 원클릭 실행 가능하며 배터리 소모와 속도 감소가 전혀 없음.

⚙️ 앱 설치 없는 무설치 방식

크롬/엣지/사파리 브라우저의 DoH (DNS over HTTPS) 설정에서 Cloudflare(1.1.1.1) 활성화.

🧪 1. SNI 차단 & 우회 원리 대화형 시뮬레이터

패킷이 KT/SKT/LGU+ 차단 벽을 지날 때 발생하는 변화를 직접 확인해보세요.

상태: 일반 HTTPS 접속 시도 보안 연결 헤더(SNI)의 평문 도메인 이름을 ISP 장비가 감지합니다.
Warning.or.kr 리다이렉트

1. 일반 접속 차단 원리

HTTPS 암호화 통신 직전, TLS Handshake 과정의 ClientHello 메세지 속에 서버 이름(SNI)이 평문으로 노출되어 KISA 차단 서버로 리다이렉트됩니다.

2. GoodbyeDPI / 유니콘 (추천)

ClientHello 패킷을 1바이트 단위로 조각내어 송신합니다. ISP 차단 장비는 조각난 패킷을 도메인으로 인지하지 못해 차단을 통과합니다.

3. DoH (DNS over HTTPS)

도메인 주소를 변환하는 DNS 요청 자체를 암호화 터널로 송수신하여 ISP 차단망의 질의 감시를 완전히 무력화합니다.

🧭 2. 나에게 딱 맞는 우회 방식 3초 진단기

⚡ 4. 기기별 3초 설치 및 설정 대화형 가이드

원하시는 우회 방법을 선택한 후 단계별로 따라 진행해 보세요.

💡 GoodbyeDPI란? 러시아 개발자 ValadikNoDN이 개발한 무료 오픈소스 프로그램으로, 윈도우 환경에서 속도 감소 없이 SNI 차단을 무력화하는 가장 깔끔한 방법입니다.
  1. 1
    공식 GitHub에서 다운로드

    GoodbyeDPI 공식 Release 페이지에서 최신 zip 압축파일을 다운로드 후 압축 해제합니다.

  2. 2
    서비스 등록 배치파일 실행

    폴더 안의 service_install_russia_blacklisted.cmd 또는 1_run_all.cmd 파일에서 마우스 우클릭 ➔ [관리자 권한으로 실행]을 클릭합니다.

  3. 3
    접속 테스트

    브라우저를 열고 기존에 차단되었던 사이트에 접속해봅니다. 재부팅 후에도 백그라운드에서 자동 유지됩니다.

🦄 유니콘 HTTPS란? 국내 기업 유니콘에서 개발한 무료 우회 앱입니다. 스마트폰 로컬에서 패킷 조작만 수행하므로 배터리 소모와 속도 감소가 거의 발생하지 않습니다.
  1. 1
    스토어에서 앱 다운로드

    구글 플레이스토어 또는 애플 앱스토어에서 '유니콘 HTTPS'를 검색하여 무료 설치합니다.

  2. 2
    스위치 활성화 (VPN 프로필 허용)

    앱 중앙의 거대한 스위치 버튼을 누른 후, 최초 1회 나타나는 '로컬 VPN 연결 허용' 팝업에서 [확인]을 누릅니다.

🌐 크롬/엣지 DoH 설정 별도의 우회 앱을 설치하고 싶지 않을 때, 브라우저 자체 암호화 DNS 기능을 활성화하여 즉시 접속하는 방법입니다.
  1. 1
    크롬 설정 ➔ 보안 이동

    Chrome 우측 상단 메뉴(⋮) ➔ [설정] ➔ [개인정보 및 보안] ➔ [보안] 메뉴로 들어갑니다.

  2. 2
    보안 연결 사용 (Cloudflare 1.1.1.1 선택)

    '보안 연결 사용' 항목을 활성화한 뒤 [다음 공급업체 사용]을 체크하고 Cloudflare (1.1.1.1)를 선택합니다.

❓ 5. 자주 묻는 질문 (FAQ)

사이트 차단 우회 시 사용자가 자주 궁금해하는 질문 모음입니다.

GoodbyeDPI나 유니콘 HTTPS 같은 SNI 파편화 프로그램은 패킷의 도메인 헤더 조각화만 수행할 뿐 외부 서버로 사용자의 데이터를 전송하지 않으므로 개인정보 유출 위험이 전혀 없습니다.

반면 출처가 불분명한 '무료 VPN'은 사용자의 통신 로그를 판매할 가능성이 있으므로 검증된 소프트웨어를 사용하는 것이 안전합니다.

해당 사이트의 도메인(주소) 자체가 완전히 변경되었거나 서버가 차단된 경우일 수 있습니다. 브라우저 캐시를 삭제(Ctrl+Shift+R)하신 후 최신 주소를 확인하세요.

유용한 최신 링크나 다시보기 정보는 웹툰·OTT 사이트 안전 가이드에서 상세히 확인하실 수 있습니다.

PC 환경에서는 GoodbyeDPI, 모바일 환경에서는 유니콘 HTTPS가 가장 빠릅니다. 두 방식 모두 VPN처럼 해외 거점 서버를 경유하지 않으므로 원래 본인의 인터넷 속도가 100% 그대로 유지됩니다.
